# 🌦️ 날씨알리미

지역명을 검색하거나 지도에서 위치를 찍어 **하루 · 일주일 · 한달** 날씨를 보는 웹 페이지입니다.
API 키 없이 동작하고, `index.html`을 더블클릭해서 열어도 됩니다.

## 기능

- **지역명 검색**: 한국어 지명(구·동·읍·면·리·역·해수욕장·산 등). 같은 이름이 여러 곳이면 구·군 이름을 붙여 후보를 보여줍니다.
  - 시골의 리는 "평창군 봉평면 창동리" 처럼 위 단위를 같이 쓰면 정확합니다. 리가 지도 자료에 없으면 면 범위로 다시 찾고 알려줍니다.
  - 날씨는 행정구역 단위가 아니라 **핀을 꽂은 좌표**(해발 고도 반영)로 계산합니다. 같은 리 안에서도 위치에 따라 값이 다를 수 있습니다.
- **지도 핀**: 지도를 누르면 그 지점에 핀이 꽂히고, 핀을 끌어 옮기면 옮긴 좌표의 날씨로 바뀝니다. 📍 내 위치 버튼도 있습니다.
- **현재 날씨**: 기온 · 체감온도 · 날씨 · 습도 · 풍속/풍향 · 오늘 강수확률 · 최고/최저
- **하루**: 앞으로 24시간 기온 그래프(가리키거나 누르면 시간별 값) + 시간별 날씨·강수확률·습도·풍속
- **일주일**: 7일 예보 — **오전·오후 날씨와 강수확률**, 최저~최고 기온 막대, 강수량, 습도, 풍속
  - 날짜를 누르면 **3시간 간격(0·3·…·21시)** 예보가 펼쳐집니다. 오늘은 지난 시간대를 뺍니다.
- **한달**: 30일 — 1~16일째는 예보(오전·오후, 3시간 간격 포함), 17~30일째는 **최근 3년 같은 날짜의 평균(예년 참고값)**
  - 날씨 예보는 약 16일까지만 존재합니다. 그 뒤는 예보가 아니라는 표시(`예년` 배지, 빗금 막대)를 붙였고, 오전·오후 구분도 없습니다.
  - 예보는 멀수록 부정확합니다. 8일째 이후는 참고용으로 보세요.
- 마지막으로 본 위치와 탭을 기억합니다. 라이트/다크 모드, 휴대폰 화면을 지원합니다.
- **앱으로 설치(PWA)**: 홈 화면에 추가하면 주소창·툴바 없이 앱처럼 뜹니다. 앱 화면에는 ↻ 새로고침 버튼이 있습니다.

### 기온 막대 읽는 법

파란 막대 하나가 그날의 **최저~최고 기온**입니다. 왼쪽 끝이 최저, 오른쪽 끝이 최고입니다.
모든 날이 목록 맨 위의 **기온 눈금**을 같이 쓰므로, 막대가 **오른쪽**에 있을수록 따뜻한 날이고
**길수록** 일교차가 큰 날입니다. 빗금 막대는 예보가 아닌 예년 평균입니다.

## 휴대폰에 앱으로 설치

웹 주소(https://zenki798.github.io/weather-alimi/)로 열어서 설치합니다. (파일을 더블클릭해 연 페이지는 설치되지 않습니다)

- **안드로이드(크롬·삼성 인터넷)**: 페이지 위쪽의 "앱으로 설치" 버튼, 또는 브라우저 메뉴(⋮) → "앱 설치" / "홈 화면에 추가"
- **아이폰·아이패드(사파리)**: 공유 버튼(□↑) → "홈 화면에 추가"
- 예전에 즐겨찾기처럼 홈 화면에 추가해 둔 아이콘은 지우고 다시 추가해야 앱 모드로 뜹니다.

## 실행

```bash
# 그냥 열기
index.html 더블클릭

# 또는 개발 서버
npm install
npm start          # http://localhost:4179
```

## 테스트

```bash
npm install
npx playwright install chromium
npx playwright test          # 데스크톱 + 모바일, 외부 API는 가짜 응답으로 대체
```
